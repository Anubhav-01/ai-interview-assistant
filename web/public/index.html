Why it's different

🔒

Privacy-first by design

Resume, job descriptions and session history never leave your machine. The only network traffic is to the AI provider you explicitly configure.

📄

Resume grounding engine

Parses your PDF/DOCX resume into structured data and answers only from verified facts — it never invents jobs, projects or certifications.

🎤

Speech → answer pipeline

Local voice-activity detection segments the interviewer's question, transcribes it, classifies it and generates a context-aware answer.

🧠

Follow-up aware

"What was the biggest challenge?" just works — a compact context engine keeps recent Q&A in memory without resending your whole interview.

💻

Coding & SQL modes

Approach, correct code, time/space complexity for coding questions. Query + concise explanation for SQL. HR answers that sound human, not corporate.

🪟

Floating window

Compact always-on-top mode with adjustable opacity and global shortcuts — plus a prominent STOP that instantly kills mic and pending requests.

Up and running in 4 steps

Download the installer above (or clone the repo and run start.bat).
Launch it — the app works instantly in free offline Mock mode.
For real answers: Settings → AI Provider → paste your own OpenAI or Gemini API key.
Upload resume → paste job description → Start Interview.

🛡 An honest note

This is a normal desktop application: fully visible in Task Manager, no hiding, no evasion of system monitoring, no telemetry. It's a free personal tool for practicing and preparing — use it responsibly and honestly.
